# Output

Figures, tables, and model objects generated by the scripts in `code/`.

```
output/
├── figures/    Plots, saved from code via ggsave()
└── tables/     Tables, written from code via write_csv()
```

## Nothing in here is tracked by Git

The folders are kept so scripts have somewhere to write. Their contents stay on your machine.

This is stricter than it may first appear necessary, and the reason is worth understanding: **a fitted model object is not a summary of your data, it contains your data.** An `lm()` object carries a `$model` component holding the complete model frame — every row that went into the fit. Saving one here and committing it would put participant-level data into the repository's permanent history, in a file that looks like a result rather than a dataset. The same is true of most fitted objects in R.

Rather than asking everyone to sort the safe outputs from the unsafe ones correctly, every time, forever, nothing in `output/` is tracked.

Nothing is lost by this. Every file here is regenerable by running `code/run_all.R`.

## Everything here is disposable

**Never hand-edit anything in `output/`.** Do not open a figure in Illustrator to fix an axis label, and do not tidy a table in Excel. The next run of the pipeline overwrites your changes without any indication that they existed. If a label is wrong, fix it in the code that draws it.

## Sharing results

Since results are not in the repository, collaborators who do not run R will not see them on GitHub. To share a specific figure or an aggregated table:

- **Preferred:** write it up in [`reports/`](../reports/README.md), which is tracked precisely so that collaborators can read results on GitHub without running anything. A figure with a sentence explaining it is more useful than a bare PNG anyway.
- **If it genuinely belongs in the repository** — a journal's supplementary materials, say — override the ignore rule for that one file:

  ```bash
  git add -f output/figures/fig1_outcome_by_condition.png
  ```

  Do this deliberately, one file at a time, and only after confirming the file shows aggregated results. A figure plotting every individual case in a study of four classrooms can identify participants even though it contains no names.

## Naming

Number outputs to match the order they appear in the report, so "Figure 2"
means one specific file:

```
fig1_outcome_by_condition.png
fig2_interaction.png
table1_descriptives.csv
table2_regression.csv
```
