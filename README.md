## How to reproduce the analysis

1. **Get access to the data.** See [`data/README.md`](data/README.md).
2. **Clone this repository.** See
   [`docs/github-guide.md`](docs/github-guide.md) if you have not done this
   before.
3. **Place the raw data** in `data/raw/`, exactly as received.
4. **Open `[PROJECT NAME].Rproj`** in RStudio. Open the `.Rproj` file itself
   rather than opening the scripts directly — it sets the working directory,
   which is what makes every file path in the code work.
5. **Install packages:** [list them, or `renv::restore()` if you use renv]
6. **If the project uses the Python helpers,** create the environment with
   `python -m venv .venv && .venv/bin/pip install -r requirements.txt`.
7. **Run `code/run_all.R`.** This reproduces everything from raw data to final
   figures and tables.

## What is in here

```
[project-name]/
├── code/            Analysis scripts, run in numbered order
│   ├── 00_setup.R      Packages, paths, seed — sourced by everything else
│   ├── 01_clean.R      Raw data → analysis-ready data
│   ├── 02_derive.R     Scale scores, composites, recodes, analytic flags
│   ├── 03_analyze.R    Models, figures, tables
│   ├── 04_report.R     Renders the reports in reports/
│   ├── run_all.R       Runs the whole pipeline start to finish
│   └── functions/      Reusable functions written for this project
├── data/            NOT tracked by Git — see data/README.md
│   ├── raw/            As received, read-only
│   └── processed/      Generated by code, disposable
├── output/          Generated figures and tables — NOT tracked by Git
│   └── reports/        Rendered PDFs and HTML, not tracked
├── reports/         Rendered summaries for people who don't run R — tracked
├── materials/       Instruments, protocols, consent forms
├── docs/            Orientation, FAQ, codebook, decisions log, guides
├── CONVENTIONS.md   How we name things and write code
└── SETUP.md         What to do when you first create this repository
```

Important rules:

- **Data never enters Git.** This includes `output/`, because a saved model object contains the data it was fit on. See [`data/README.md`](data/README.md) and [`output/README.md`](output/README.md).
- **Every result comes from code.** No hand-edited figures, no numbers typed into a table by hand.
